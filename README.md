# Постобработка OCR паспорта РФ

Строгий вариант решения задания из TASK.md. Приоритет - отсутствие ошибочных
принятий на проверках; сомнительные документы отклоняются.

- Весь train: **45 принятых из 3000, 0 ошибочных** по исходному evaluate.py.
- Календарно недействительных среди принятых train: **0**.
- Test: **45 принятых из 2000**, 1955 отклонённых; прогноз ошибок - **0**.
- Фактическое число ошибок test неизвестно: закрытой разметки нет.
- Проверка после переработки повторная, не новая независимая валидация.

## Запуск

Нужен Python 3.9 или новее. Для решения не нужны пакеты, GPU и интернет.

```bash
python3 postprocess.py data/test_predictions.jsonl answers.jsonl
```

Команда из условия также работает, если python указывает на Python 3:

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Пути могут быть абсолютными. Справочник ищется рядом со скриптом, независимо от
текущего каталога. У accept есть все 10 полей; у reject только doc_id и decision.
Повреждённый JSON или повтор doc_id останавливает выполнение; частичный результат
после такой ошибки сдавать нельзя.

## Проверки

```bash
python3 -m unittest -v test_postprocess.py
python3 validate.py
python3 postprocess.py data/train_predictions.jsonl results/train_answers.jsonl
python3 evaluate.py results/train_answers.jsonl data/train_labels.jsonl
```

19 модульных тестов проверяют контрольные цифры, потерю строк, несовпадение зон,
пороги уверенности и границы дат. validate.py дополнительно требует ноль ошибок
среди принятых размеченных документов и ноль календарно недействительных принятий.
Любое такое нарушение завершает проверку с ошибкой.

## Критерии принятия

Принимается только источник mobile. Обязательны полнота геометрии полей,
посимвольная уверенность не ниже 0,99 **во всех визуальных полях и обеих строках MRZ**,
полное совпадение построенной и распознанной MRZ, корректные контрольные цифры,
форматы, код подразделения и календарная действительность на 01.10.2026.

Ошибочное значение не исправляется догадкой. Справочник проверяет код, но не
подменяет историческое название органа. Исключение для отсутствующего отчества
возможно только при согласии с MRZ. После 20/45-летия учитываются 90 дней включительно;
для рождения 29 февраля годовщина невисокосного года считается 28 февраля.
Реестровую действительность по этим данным проверить нельзя.

Режимы с ненулевыми ошибками удалены из актуального интерфейса. Основной файл
answers.jsonl соответствует только строгим правилам. Диагностика по документам:

```bash
python3 postprocess.py data/test_predictions.jsonl answers.jsonl --diagnostics results/test_diagnostics.jsonl
```

## Содержимое

- postprocess.py, answers.jsonl - код и окончательные ответы test.
- REPORT.pdf - отчёт на 2 страницах; REPORT.md - редактируемый текст.
- evaluate.py - проверяющий скрипт из задания, без изменений.
- validate.py, split.json, metrics.json - воспроизводимые проверки и метрики.
- test_postprocess.py - модульные тесты.
- results/ - актуальные ответы train, диагностика и логи.
- data/ - три исходных JSONL; reference/ - исходный справочник и атрибуция.
- download_manifest.json - ссылки и SHA-256 исходных файлов.
- build_report.py - необязательная сборка отчёта; только для неё нужны reportlab и шрифты.

Предыдущее разбиение development/holdout сохранено. После повторного использования
holdout при переработке его нельзя считать независимым. Нулевой наблюдаемый результат
не является доказательством нулевого риска на неизвестных документах. Подробности -
в отчёте; никакой подстановки train_labels.jsonl во время обработки нет.

## Репозиторий и исходные данные

Решение: https://github.com/sonykutuzova/passport-ocr

Репозиторий закрытый: для просмотра проверяющему нужен доступ.
В репозитории находятся код, answers.jsonl, отчёт и справочник.
Исходные JSONL следует положить в data/ перед повторением обработки и оценки.
Ссылки на исходные файлы и их контрольные суммы указаны в download_manifest.json.
После клонирования перед записью диагностических файлов создайте каталог:

```bash
mkdir -p results
```

Данные data/, диагностические результаты results/ и резервный архив предыдущей
версии исключены из Git и не входят в сдаваемое решение.
