Постобработка OCR паспорта РФ с приоритетом минимизации ошибочных принятий.

Решение сопоставляет визуальные поля с MRZ, проверяет уверенность распознавания, полноту полей, код подразделения и календарный срок действия. Работает на CPU без интернета и сторонних библиотек.

Код - postprocess.py, ответы для test - answers.jsonl, описание подхода и результаты - REPORT.pdf. В reference/ находится используемый справочник подразделений.
