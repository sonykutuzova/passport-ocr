# Постобработка OCR паспорта РФ

## Запуск

Python 3.9+, CPU, без интернета и сторонних библиотек.
Входной файл возьмите из материалов задания.

```bash
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Если Python 3 доступен командой `python3`, используйте её вместо `python`.

## Файлы

- `postprocess.py` — код решения.
- `answers.jsonl` — ответы на 2000 тестовых документов.
- `REPORT.pdf` — отчёт на двух страницах.
- `reference/` — справочник подразделений, необходимый скрипту, и атрибуция источника.

На доступной разметке: 45 принятых из 3000, 0 ошибочных принятий.
На test: 45 принятых из 2000; прогноз ошибок — 0.
Это прогноз, а не подтверждённый результат: разметка test недоступна,
а проверка после переработки решения не была независимой. Подробности — в отчёте.
